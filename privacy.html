Privacy Policy — AI Framework Continuity

Updated October 23, 2026.

Purpose and operator

AI Framework Continuity is a personal project operated by Brandon Heidel. Its Windows continuity tool preserves project files, progress records and recovery information in the owner's Google Drive.

Google Drive access and use

The tool uses Google authorization through rclone. Its current authorization grants broad Drive access; the continuity tool's configured operations are restricted to the AI Framework Project folder. That folder restriction is an application configuration, not a Google-enforced limitation on the authorization.

The tool accesses file contents and metadata to upload project records, download copies for verification, and maintain transfer manifests, receipts and status records. Records can include file names, paths, hashes, timestamps and computer identifiers.

Storage and sharing

Project records and recovery copies are stored on the owner's computer and in the configured Google Drive folder. Google processes data as the storage provider. OAuth credentials are stored locally outside the project transfer folders.

The continuity tool does not sell Google user data or use it for advertising. It does not send file contents to an AI model as part of its backup and transfer-verification operations. Separately authorized AI processing is outside this tool's current scope.

Retention and deletion

Local records, uploaded versions and archives are retained until the owner removes them. Deleting an original file does not automatically delete its recovery copies. Removing copies from one location does not remove copies stored elsewhere.

Control and revocation

The owner can stop the Windows continuity task and revoke the app's access through Google Account third-party connections. Revocation prevents future authorized access but does not delete existing local or Drive copies.
